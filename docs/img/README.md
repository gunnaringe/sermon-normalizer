# Pictures of the documentation

Made by `scripts/test.sh guide` (after `scripts/fetch-sample.sh`) from a real speech with the real app: see
`web/e2e/guide/guide.spec.js`. Run it again when the interface changes.

The speech is President John F. Kennedy's inaugural address, 20 January 1961: a work of the US federal
government, in the public domain
([source](https://commons.wikimedia.org/wiki/File:JFK_inaugural_address.ogg)). The audio is not kept in this repository.
